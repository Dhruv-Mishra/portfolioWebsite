This portfolio is a sketchbook-themed site built with Astro, React 19 islands, Tailwind v4, and Framer Motion. It has an interactive retro terminal, an AI chat, a guestbook, and an unlockable sticker system. It runs on VM-backed Astro Node for the current migration phase, with Cloudflare edge caching, Nginx reverse proxies, GitHub Actions CI/CD, and a local VM TTS sidecar path. The next infrastructure step is moving the static/public shell toward Cloudflare Workers while keeping local TTS on VM infrastructure.
