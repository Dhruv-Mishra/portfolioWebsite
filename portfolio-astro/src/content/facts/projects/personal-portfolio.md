The portfolio website itself — a high-performance Astro Node site using React 19 islands, TypeScript, Tailwind v4, and Framer Motion, with a hand-drawn sketchbook aesthetic (custom pencil/chalk cursor, paper textures, torn tape strips). Features an AI-powered chat, an interactive retro terminal, a guestbook, an unlockable sticker system, and a custom command palette. Infrastructure currently uses VM-backed Node with Cloudflare edge caching, Nginx reverse proxies, Docker image packaging, and GitHub Actions CI/CD; local TTS stays on VM infrastructure while the static/public shell is prepared for a future Cloudflare Workers phase. Stack: Astro, React, TypeScript, Tailwind CSS, Cloudflare, Nginx, Docker, GitHub Actions. Year: 2025, ongoing. Repo: github.com/Dhruv-Mishra/portfolioWebsite.
