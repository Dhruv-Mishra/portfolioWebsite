This portfolio is a sketchbook-themed site built with Next.js 16, React 19, Tailwind v4, and Framer Motion. It has an interactive retro terminal, an AI chat, native on-page voice mode, a guestbook, and an unlockable sticker system. It runs across multi-cloud VMs on Azure, GCP, and Oracle Cloud with a custom traffic manager, distributed backend, Cloudflare edge caching, Nginx reverse proxies, and parallel GitHub Actions CI/CD — everything free, only paying for the domain.
