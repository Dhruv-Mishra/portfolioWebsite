This portfolio is a sketchbook-themed site built with Next.js 16, React 19, Tailwind v4, and Framer Motion. It has a live voice agent you can interrupt mid-sentence, a RAG chatbot with 5 selectable LLMs, a retro terminal, a guestbook, and unlockable stickers. It ships as Docker images through GitHub Actions to Linux VMs on Azure, GCP, and Oracle Cloud, behind Nginx and Cloudflare. Everything is free except the domain.
