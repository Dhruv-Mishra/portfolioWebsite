Fluent UI Android is the official Microsoft native Android library enabling developers to build uniform Microsoft 365 experiences. I managed its release lifecycle as sole owner across 10 releases for 10+ partner teams including Copilot, Office, Outlook, OneDrive, and Teams. The library is Kotlin/Java with Jetpack Compose, XML layouts, Gradle/Maven builds, official Fluent design tokens, typography styles, and custom controls for the Microsoft ecosystem. Stack: Kotlin, Java, Android SDK, Jetpack Compose, XML, Gradle, Maven, Design Systems, API Design. Repo: github.com/microsoft/fluentui-android.
