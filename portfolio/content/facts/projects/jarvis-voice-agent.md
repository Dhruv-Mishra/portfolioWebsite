Jarvis is a voice AI dispatch agent I built for a demo logistics app (Dhruv FreightOps). You place a call and talk to it: it looks up loads, assigns carriers, negotiates freight rates, submits quotes, schedules callbacks, and moves around the app for you. It uses an LLM planner with MCP tools and RAG over load and carrier data, and it acts on the page through tool calls. It's a personal side project I built on my own time. It is NOT a Microsoft product and is not affiliated with my employer's work. Live demo at jarvis.whoisdhruv.com (anyone can try it). Source code is public at github.com/Dhruv-Mishra/AudioControlledAgenticWebsite. Architecture: a vanilla HTML/CSS/JS frontend with an AudioWorklet capturing 16 kHz PCM, and a Node.js backend that bridges a long-lived WebSocket to a live voice model. The UX follows a phone call: Place Call and End Call, optional call-center background noise, phone-line band-pass filtering, five personas, barge-in, and native voice activity detection. The WebSocket, AudioContext, and microphone live in one long-lived page shell, so the call doesn't drop when you move between pages. No audio is uploaded until the call starts, context is compressed with a sliding window at 80k tokens, and the system prompt and tool schemas stay stable so prompt caching works. Stack: JavaScript, Node.js, WebSockets, AudioWorklet, MCP, RAG, Tool Calling. Year: 2026, ongoing. Repo: github.com/Dhruv-Mishra/AudioControlledAgenticWebsite. Live demo: jarvis.whoisdhruv.com.
