This portfolio website, whoisdhruv.com. It's a server-rendered Next.js 16, React 19, TypeScript, and Tailwind v4 site with a hand-drawn sketchbook look (pencil cursor, paper textures, tape strips). The main feature is a live voice agent you can talk to and interrupt mid-sentence: full-duplex audio streams over a WebSocket, and the agent has 25+ tools to navigate pages, open projects, fill forms, and run terminal commands for you. Start it from the Talk to me note on the homepage, from settings, or from chat; the call stays on whatever page you're on. There's also a RAG chatbot that answers questions about my work and projects from a curated fact base, with 5 selectable LLMs, one of which is a self-hosted model. Plus a retro terminal, a guestbook, and unlockable stickers. It's deployed as Docker images through GitHub Actions to Linux VMs on Azure, GCP, and Oracle Cloud, behind Nginx and Cloudflare. Everything is free except the domain. Stack: Next.js, React, TypeScript, Tailwind CSS, Gemini Live, RAG, Docker, GitHub Actions, Nginx, Cloudflare. Year: 2025, ongoing.
