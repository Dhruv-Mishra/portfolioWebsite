The portfolio website itself — a high-performance server-rendered site built with Next.js 16, React 19, TypeScript, Tailwind v4, and Framer Motion. Visitors can pass sticky-note chat, optionally dictate into it, and ask the site to navigate, open projects, control project videos, or change theme and volume through guarded actions. The rest of the experience includes an interactive retro terminal, guestbook, unlockable sticker system, command palette, custom pencil/chalk cursor, paper textures, and torn tape strips. Infrastructure: georedundant deployment across Azure, GCP, and Oracle Cloud VMs with custom traffic routing, Nginx reverse proxies, Cloudflare caching, and parallel GitHub Actions CI/CD pipelines. Everything is free except the domain. Stack: Next.js, React, TypeScript, RAG chat, Tailwind CSS, Azure, GCP, Oracle Cloud, and Nginx. Year: 2025, ongoing. Repo: github.com/Dhruv-Mishra/portfolioWebsite.
