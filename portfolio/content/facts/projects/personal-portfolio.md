The portfolio website itself — a high-performance server-rendered site built with Next.js 16, React 19, TypeScript, Tailwind v4, and Framer Motion, with a hand-drawn sketchbook aesthetic (custom pencil/chalk cursor, paper textures, torn tape strips). Features an AI-powered chat, an interactive retro terminal, a guestbook, an unlockable sticker system, and a custom command palette. Native on-page voice mode answers in first person and can navigate or act with the same tools as chat; enter it from the homepage Talk to me note, settings, the command palette, or chat — the call stays on the current route. Infrastructure: multi-cloud VMs across Azure, GCP, and Oracle Cloud with a custom traffic manager, distributed backend, Cloudflare edge caching, Nginx reverse proxies, and parallel GitHub Actions CI/CD. Everything free except the domain. Stack: Next.js, React, TypeScript, Tailwind CSS, Azure, GCP, Oracle Cloud, Nginx. Year: 2025, ongoing. Repo: github.com/Dhruv-Mishra/portfolioWebsite.
